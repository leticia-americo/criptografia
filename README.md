# Mensagens Secretas

Um programa em Python que transforma mensagens em códigos secretos e também descobre o que está escrito neles!

## Como funciona

- **Criptografar:** você digita uma mensagem e um número (a chave), e cada letra é deslocada de acordo com esse número
- **Descriptografar:** você digita a mensagem codificada e o programa mostra o resultado com todas as chaves de 1 a 25
- **Sair:** encerra o programa

## Como jogar

1. Instale o Python
2. Execute o arquivo:

```
python criptografia.py
```
